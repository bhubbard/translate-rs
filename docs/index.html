translate-rs — Pure Rust Offline Neural Machine Translation

🔒 100% Offline & Private

Translates text locally on CPU or Apple Silicon NPU. No data ever leaves the local machine.

⚡ Sub-5ms Inline Speed

Fast enough to translate real-time game dialogue, interactive UI strings, and chat feeds without lag.

🌍 Full Language Coverage

English, Spanish, French, German, Japanese, Chinese, Italian, and Portuguese support with BLEU parity.

🪶 Tiny 68 MB RAM Footprint

Consumes 9× less RAM than Python translation servers, running comfortably as a background system daemon.
