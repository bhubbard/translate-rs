🎯 Bit-for-Bit BLEU Parity

Both translate-rs and translate.franzai.com harness Apple's native on-device neural translation models. Output translation quality and BLEU scores are identical across English, Spanish, German, French, and Japanese (Δ = 0.0).

🛡️ Framework Memory Isolation

Apple's translation framework can cache internal structures. By delegating neural inference to an ephemeral native bridge worker, translate-rs prevents memory creep in the Axum HTTP daemon, staying locked at ~3.4 MB RSS indefinitely.

🔌 Drop-in Multi-API Wire Parity

Compatible with DeepL v2 (POST /v2/translate), LibreTranslate (POST /translate), and Google Cloud Translation v2 (POST /language/translate/v2). Existing clients, browser extensions, and SDKs plug in seamlessly.
